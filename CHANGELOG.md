# Changelog

## 1.0.0

- First npm release: `npx @minhspark/ai-agent-company` starts the hub, `demo` shows sample agents, `install-claude-hook` installs the Claude approval hook.
- The hub ships as one built server file (`dist-server/hub.mjs`) with the built web UI, so the package has no runtime dependencies.
- CI builds, tests and starts the packaged hub in demo mode on every push.
